# Claude Qwen Enterprise configuration

Cross-platform project: Windows 10/11 (PowerShell 5.1+), Ubuntu 20.04+ and macOS 11+ (bash, python3 stdlib). All platforms share `qwen-settings.json`, `qwen-agents.json`, and `agents/`.

- `claude-qwen.ps1` (Windows) and `claude-qwen.sh` (Linux/macOS) own launcher, credential, status, and smoke-test commands. Windows stores the key in Windows Credential Manager; macOS uses the login Keychain (`security add/find/delete-generic-password`, service `claude-qwen-enterprise`); Linux uses libsecret (`secret-tool`) when available. Both Unix systems fall back to `~/.config/claude-qwen-enterprise/api-key` (0600).
- `claude-qwen.sh` must stay compatible with bash 3.2 (the stock macOS bash): no `compgen -e`, no associative arrays, no `${var,,}`; use `compgen -A export` and POSIX constructs.
- `test-qwen.ps1` (Windows) and `test-qwen.py` (Linux/macOS) are the end-to-end smoke tests run by `claude-qwen-test`. Keep their checks and result names in sync.
- `install.ps1` / `install.sh` copy the app to a stable per-user location (`%LOCALAPPDATA%\ClaudeQwenEnterprise\app` / `~/.local/share/claude-qwen-enterprise/app`) and install shims into `%USERPROFILE%\.local\bin` / `~/.local/bin` (creating it and adding it to PATH if needed; `~/.profile`+`~/.bashrc` on Linux, `~/.zprofile`+`~/.zshrc`+`~/.bash_profile` on macOS).
- `install-remote.ps1` / `install-remote.sh` are the one-command entry points (`irm ... | iex` / `curl ... | bash`): they download this repository and run the local installer. Keep their owner/name/branch variables and the README one-liners in sync with the published repository URL; both refuse to run while the `TU-USUARIO` placeholder is present.

Install with `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1` (Windows) or `bash ./install.sh` (Linux) from this directory. After editing launcher, settings, test, or agent files, re-run the installer so the installed app copy picks up the change. Run `claude-qwen-status` for a safe local check and `claude-qwen-test` after enrolling a key.

Conventions: keep `.sh`/`.py` files LF-only (enforced by `.gitattributes`) and keep them recorded as executable in the git index (`git update-index --chmod=+x <file>`; mode 100755) so Unix clones can run `./install.sh` directly. Keep console messages in the `.ps1`/`.sh` installers and launchers ASCII-only so they render correctly under Windows PowerShell 5.1 code pages and minimal Linux/macOS locales. The macOS code paths (Keychain via `security`, zsh PATH setup, bash 3.2 compatibility) were reviewed and stub-tested from Windows, not yet exercised on a real Mac; when changing them, verify on macOS if possible. Never copy the official Claude credential file or an API key into this repository.
